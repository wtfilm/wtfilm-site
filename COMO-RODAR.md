# Como rodar o projeto wtfilm

## 1. Instalar dependências (só na primeira vez)

Abra o Terminal, navegue até esta pasta e rode:

```bash
cd ~/Desktop/site-wtfilm\ 3/wtfilm-site
npm install
```

## 2. Rodar o projeto localmente

```bash
npm run dev
```

O site abre em: http://localhost:3000
O painel Sanity abre em: http://localhost:3000/studio

## 3. Parar o servidor

Pressione `Ctrl + C` no Terminal.
